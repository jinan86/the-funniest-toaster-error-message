## The entry

> SLOT_B: Unrecognized item. I have never met this bread before in my life.

The toaster doesn't apologise, doesn't blame the bread, doesn't reach for a pun — it simply denies ever having met the bread. Deadpan, one voice, lands on a single read.

## How it works

`main.py` is a deterministic Python 3 program. It writes the line above to `/output/entry.txt` — the same bytes on every run. No network, no randomness, no input.

```sh
python3 main.py
cat /output/entry.txt
```
